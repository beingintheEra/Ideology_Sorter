# LeftwtSorter

![Ideology Sorter icon](assets/logos/embed.svg)

A branching political ideology test. Choose answers to reach a result, open Tree to explore the question flow, or use Create to make a custom result card with your own flag, name, and quote.

The source is available on [GitHub](https://github.com/beingintheEra/Leftwtsorter). Licensed under [GPL-3.0](LICENSE).

Large language models helped draft parts of the code and text. They can make mistakes; the questions and results should not be treated as authoritative descriptions of political ideas.
